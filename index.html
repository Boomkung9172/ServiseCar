ตั้งค่า Google Client ID (เชื่อมต่อจริง)

ระบบรองรับ Google Identity Services (GIS) มาตรฐานสากล คุณสามารถนำ Client ID จาก Google Cloud Console มาเชื่อมต่อเพื่อทดสอบการล็อกอินด้วยบัญชี Google จริงได้ทันที

สถานะ: กำลังตรวจสอบ Client ID...
วิธีขอ Google Client ID ฟรีใน 2 นาที:
  1. เปิด Google Cloud Console (ใช้บัญชี Gmail ทั่วไปได้ฟรี)
  2. กด Create Credentials แล้วเลือก OAuth client ID
  3. เลือก Application type เป็น Web application
  4. ในช่อง Authorized JavaScript origins ให้ใส่:
    http://localhost:8080
  5. กดปุ่ม Create แล้วนำ Client ID ที่ได้มาวางในช่องด้านบน แล้วกด "บันทึก Client ID"

ข้อควรปฏิบัติเมื่อรถเสีย

  • 1. เปิดสัญญาณไฟฉุกเฉินทันที
